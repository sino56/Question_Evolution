# 设计条目 ↔ 实现 ↔ 测试 映射表

**用途**：把审查报告（`docs/Agent改造方案/Agent_Harness_代码审查报告_2026-09-11.md`）里的每一条缺陷绑定到具体实现位置与回归测试，避免"设计有承诺、实现无落点、测试无覆盖"的三方漂移（报告 X-4）。

**维护规则**

1. 每条缺陷必须同时具备「实现位置」与「测试用例」两列；只改实现不改测试视为未完成。
2. 新增契约（schema / 枚举 / 常量）必须同步更新 `tests/test_agent_contract_drift.py` 的漂移断言。
3. 本表由 `tests/test_agent_contract_drift.py` 校验：表中引用的路径必须真实存在，且缺陷编号必须齐全。
