- 文档状态：已实施第一部分
- 制定日期：2026-07-22
- 适用范围：四类视频研判场景暴露出的多跳证据、实体解析、多假设、观测可靠性、关系网络和跨模态能力缺口
- 前置方案：《新算子扩充方案》《四场景现有算子修复方案》《扩大实验与受控评测方案》
- 目标读者：负责新 operator spec、场景数据标注、生成 Prompt、专属 payload、Router 和资格实验的研发与评测人员
- 读完后应能完成：分别实现四场景新算子的内容定义与校准/机制契约，并能判断一项改动应归入哪一部分

## 1. 文档边界

本方案拆成两个职责独立的部分：

1. **第一部分：新算子内容设计** 确定 O28-O33 的稳定编号，定义各自测什么、题面如何构造、内容如何变换、保留什么推理负担、目标错误是什么，以及与 O19-O27 的相邻内容边界；并完成基础 registry 注册、现有 Router 的规则识别和生成 Prompt 调用接线。
2. **第二部分：校准与机制优化** 根据第一部分确定的稳定编号，负责 O28-O33 的语义冲突校验、semantic version、资格状态，以及 Schema、payload、answer contract、scorer、场景 Adapter、Router 适用性契约与质量校准、validator、门控、发布、回滚和数据校准。基础注册、现有 Router 可识别和生成调用不再延后到第二部分。

第一部分中的"必须"和"不得"只表示算子内容和 Prompt 构造要求，不自动等于程序化校验或 blocking 规则。如需人工审核，可保存审核关注点和备注；这些记录只供后续人工查阅，不作为准入、排序、重试、拒绝、路由、评分、状态迁移或发布的判断依据。第一部分的可调用只表示现有流水线能够选择并执行算子，不表示已经通过资格、正式启用或获得新增发布保障。

四场景评估报告提出了六个临时新算子方向，并临时使用 O19-O24 编号。《新算子扩充方案》已经为 O19-O27 分配了稳定语义，因此本方案不将四场景新算子穿插到已有编号中，而是统一使用紧接 O27 的 O28-O33 作为内容编号。

编号原则：

- O19-O27 保留原有 ID 和语义，只作 O28-O33 的相邻内容边界；
- 四场景六个新方向使用连续的 O28-O33 内容编号，不复用、覆盖或重新解释 O19-O27；
- 四场景业务名称不进入 operator 语义；同一 operator 应能跨不同业务表面保持相同的能力定义。

## 4. O28 内容设计：多跳链路闭合

### 4.1 能力轴

在跨阶段、跨节点并可涉及实体转移的事件链中，判断已知事实是否足以闭合目标链路，区分已成立的局部链、仍缺失的链路和被事实反证的链路。

该算子测量的是"整体链路能否闭合"，不以事实、节点、实体或路径的数量定义难度。

### 4.2 推理对象

- 有序事件节点及其前后状态；
- 节点之间的必需边、可选边和冲突边；
- 跨节点实体绑定和转移关系；
- 路径、时间和端点约束；
- 局部已闭合链、链路断点与目标整体链。

### 4.3 题面与变换

题面应明确给出可观察节点、状态、边和约束。仅在题面具有显式路径信息时使用路径闭合维度；普通叙述中的"沿途监控"或"路线接力"不能替代图节点、可用边、时间窗和通行范围。

内容变换可调整与目标链路相关的节点状态、连接边、实体绑定、时间窗或路径可达性；目标事件类型、未参与变换的事实和目标结论层级保持不变。不得补造盲区状态、节点、边、通行关系或实体转移。

题面只询问现有材料能否支持目标事件链及依据；已成立的局部链、关键断点、断点后不可推出的状态，以及证据不完整与反证的区分保留为内部答案结构。

### 4.4 目标错误与相邻边界

目标错误包括：cross_stage_link_omitted、entity_binding_broken_across_hops、partial_chain_treated_as_closed、path_time_constraint_ignored、missing_hop_filled_by_assumption。

- O20 主要定位多阶段状态链的状态断点；O28 判断跨阶段、跨节点且可涉及实体绑定的目标链路整体是否闭合。
- O22 主要判断路径拓扑可达性；O28 可使用路径约束，但主要推理对象仍是完整事件链。
- O11 检查局部端点和时序一致性；O28 维护这些约束在整条链中的传递。

### 4.5 生成 Prompt 要求

Prompt 应在内部构造可审计的事件链、链路缺口及局部结论，公开题面只呈现自然事实和目标判断；不得显示状态图、路径清单或链路检查步骤，不得泄漏目标错误、预期答案方向或完整推理链，也不得用节点数量替代链路复杂度。

## 5. O29 内容设计：实体同一性冲突消解

### 5.1 能力轴

在多镜头、遮挡、转移或竞争来源中，综合已有绑定、时空连续性和冲突事实，判断人员、车辆、物品或容器的同一性命题能够成立、应当降级还是无法确定。

### 5.2 推理对象

- 候选实体、局部绑定和目标同一性命题；
- 可观察属性、位置、时间和转移关系；
- 遮挡、转移缺口和竞争来源；
- 支持同一性的事实、反对事实与未解决冲突。

### 5.3 题面与变换

题面应提供具有真实竞争关系的候选实体、绑定或来源，以及可观察属性、时空关系和可能存在的转移缺口。候选实体、绑定和来源的数量不作为成题条件。

内容变换可调整与目标同一性相关的外观属性、位置、时间、转移关系或冲突绑定；实体类型、未变更事实和目标命题保持不变。仅凭外观、包装、容器类别、共现或携带者相同不得直接确认同一性；人员绑定不能替代物品绑定，局部绑定不能无条件扩展到全程。

题面只询问现有材料对目标实体同一性能够支持何种判断及依据；支持、冲突、缺失关系和无法消解时的不确定性保留为内部答案结构。

### 5.4 目标错误与相邻边界

目标错误包括：appearance_only_identity、conflicting_binding_ignored、transfer_gap_ignored、local_identity_overextended、person_binding_substituted_for_object_binding。

- O19 测实体与角色的局部绑定；O29 测多个已有绑定发生冲突时如何消解同一性。
- O21 测物品来源链；O29 可使用来源事实，但目标是实体是否连续一致。
- O23 测观测自身是否可靠；O29 使用题面给出的观测条件解决跨观测实体冲突。

### 5.5 生成 Prompt 要求

Prompt 应在内部构造可审计的同一性支持与冲突，允许结论降级或保持未知；公开题面不得列出支持/冲突/缺失作答提纲，不得用外观相似、标签名称或候选数量暗示答案，也不得泄漏目标错误和完整答案链。

## 6. O30 内容设计：主动判别观测选择

### 6.1 能力轴

在保持可行的竞争假设下，从可观察新信息中选择预期最能改变假设区分度的观测，并说明可能观测结果如何更新假设关系。假设、候选观测和观测结果不设固定数量。

该算子测量的是"下一步看什么"，不是"当前哪个假设最可能"。

### 6.2 推理对象

- 当前竞争假设及其共享观察事实；
- 当前覆盖、冲突和残差；
- 可获得的候选观测及其可能结果；
- 观测结果对各假设的区分关系；
- 目标信息选择。

### 6.3 适用条件

1. 竞争假设在当前事实下均具有可行性，且数量不作为成题条件。
2. 题面提供可实际获得的候选观测，数量不作为成题条件。
3. 每个候选观测的可能结果可由题面定义。
4. 候选观测之间存在可比较的假设区分力，并允许并列最优或无法唯一判别；不得有某个候选在所有可能结果下都显然淘汰更多假设而形成表面支配。
5. 不依赖题外数据库、秘密侦查手段或未授权业务知识。

### 6.4 题面与变换

题面给出当前事实、竞争假设和可获得的候选观测，但不预填判别矩阵。内容变换可调整与目标推理相关的候选观测结果或可获得性；当前事实、假设定义和目标任务保持不变。

内容不变量包括当前已观察事实、竞争假设定义、目标命题层级和其他候选观测的质量条件。不得靠"更可疑""更权威""信息更多"等标签选择观测，也不得将不可获得的身份库、通信记录或题外侦查手段作为默认候选。

题面只询问下一步获取哪项观测最有助于继续判断及依据，不直接说明"尽量减少剩余可行解释"等选择准则。各候选观测的可能结果、结果出现后仍可行的解释和选择目标保留为内部答案结构；题目允许并列最优或无法唯一判别，但不得预填结果分支比较表。

### 6.5 目标错误

- most_suspicious_observation_selected：选择看起来最可疑而非最有区分力的观测；
- outcome_branches_ignored：没有比较观测的不同可能结果；
- hypothesis_coverage_not_updated：获得信息后未更新覆盖和残差；
- unavailable_observation_selected：选择题面不可获得的信息；
- certainty_gain_overstated：信息只能缩小范围却被写成直接定性。

### 6.6 相邻边界

- O24 排序当前假设；O30 选择下一观测。
- O16 比较目标解释与相近解释的已有 discriminator；O30 在候选观测中作主动选择。二者的边界不由解释或观测数量决定。
- O23 判断某个观测本身是否可靠；O30 默认候选观测的质量条件已给出。
- 资源成本、风险或处置优先级不是 O30 的主轴；若引入成本，只能作为题面明示的并列约束。

### 6.7 四场景内容种子

- 笑气：区分普通往返、存放补货和二次分装，应优先观察哪一可见变化。
- 电动车：区分偶然共现、同行和协同关系，应优先观察同步、等待、汇合还是独立离场。
- 涉黄：区分普通住户、接送和看管关系，应优先观察哪些重复关系节点。
- 拉车门：区分找车、误触和逐车试探，应优先观察连续动作、目标选择还是离场路径。

这些只是内容种子，不是固定答案模板。

### 6.8 生成 Prompt 要求

Prompt 应给出均可行的竞争假设、可获得观测及理解结果分支所需的事实，内部按各结果下剩余可行解释的多少比较区分力；公开题面只要求选择下一观测并说明依据，不列出分支评估步骤。不得以"更可疑""更权威"、候选顺序或明显支配关系暗示选择，也不得泄漏目标错误和完整答案链。

## 7. O31 内容设计：观测可靠度与累积校准

### 7.1 能力轴

在多次观测中区分重复、相关和相对独立的信息，判断累积观察对事实支持度和结论上限的真实增量。

该算子不要求伪造统计概率。它使用题面明示的来源关系、时间间隔、视角和重复条件进行定性或偏序校准。

### 7.2 推理对象

- 观测事件、可见特征和质量条件；
- 来源、时间窗和依赖关系；
- 重复模式与新增信息；
- 目标命题、累积支持偏序和最高允许结论。

### 7.3 适用条件

1. 题面提供针对同一目标命题的重复、相关或相对独立观测，不规定观测数量。
2. 题面能判断观测是同源重复、相关复制还是具有新增独立信息。
3. 各观测的质量和可见特征可审计。
4. 目标任务比较累积支持，而非计算未提供的概率。

### 7.4 题面与变换

内容变换可调整与目标推理相关的观测独立性、质量、时间同步或新增特征；事件、目标命题和未参与变换的观测定义保持不变。

内容不变量包括目标事件、目标命题、未变更观测及其来源关系、结论层级和比较口径。不得用重复次数直接编码答案，不得暗示不同摄像头必然独立，也不得在题面未给出概率模型时要求计算置信度。

题面只询问累积观测对目标判断增加了多少支持、最高能支持何种结论及依据。逐次新增信息、同源依赖、累积支持偏序和结论上限保留为内部答案结构。候选观测不得把来源独立、视角新增和质量提升集中在同一项上形成明显优势。

### 7.5 目标错误

- repetition_counted_as_independence；
- shared_source_dependency_ignored；
- low_quality_repeat_overweighted；
- new_feature_increment_ignored；
- cumulative_support_promoted_to_certainty。

### 7.6 相邻边界

- O23 判断观测自身是否可用；O31 判断观测之间是否有独立增量。
- O10 识别最小充分事实集合；O31 关注重复观察的依赖结构和累积支持偏序。
- O18 使用统计基线判断异常性；O31 不需要历史基线。
- O26 在明示数值、误差和阈值下计算；O31 默认不做未授权概率计算。

### 7.7 四场景内容种子

- 夜间连续拉车门：多个低质同角度画面与新增侧面清晰画面的信息增量不同。
- 仓储搬运：同一摄像头中的多次重复与不同点位形成的独立链路证据不同。
- 望风协同：多次同步出现若来自同一连续片段，不能当作多份独立支持。
- 居民楼出入：重复出入模式增加行为模式支持，但仍不能直接确认角色或违法性质。

### 7.8 生成 Prompt 要求

Prompt 应自然呈现判断观测来源、依赖、质量和新增特征所需的事实，内部比较累积前后的支持偏序；公开题面不得逐项命名这些维度。不得用观测次数、摄像头数量、顺序或将多项优势集中于同一观测来暗示答案，也不得泄漏目标错误和完整答案链。

## 8. O32 内容设计：角色关系图最小边

### 8.1 能力轴

在实体-观测-关系-角色图中，判断哪些关系边对目标角色或协同结论必要，以及边变化后哪些局部结论仍可保留。

### 8.2 推理对象

- 实体、观测和候选角色；
- 有方向的关系边及其事实来源；
- 目标角色或协同命题；
- 对目标结论必要、非必要或相互替代的关系边；
- 边变化后仍成立的局部关系。

### 8.3 题面与变换

题面应以自然场景事实呈现实体现象和有方向的关系线索，使回答者自行建立关系并判断目标角色或协同结论。不得直接给出关系图、关键边标签或边变化清单；实体、关系、角色和语义轴的数量不作为成题条件。

内容变换可交换实体绑定，删除、替换或反转与目标推理相关的关系边；与目标能力无关的动作、时间、物品来源和目标关系类型保持不变。外观相似但路径冲突、路径连续但角色方向不同、共现不等于协同，以及交换实体标签后图语义不变，可作为内容控制。

题面只询问现有关系事实能否支持目标角色或协同判断及依据；关键边、边方向、替代关系和局部保留结论保留为内部答案结构。

### 8.4 目标错误与相邻边界

目标错误包括：critical_edge_missed、noncritical_edge_treated_as_necessary、role_direction_reversed、cooccurrence_promoted_to_coordination。

- O19 测实体与角色绑定；O32 测关系图中哪些边对目标角色结论必要。
- O13 测事实移除对局部连接的影响；O32 维护完整关系图及边方向、必要性和替代关系。
- O29 解决实体同一性冲突；O32 默认题面中用于关系图的实体绑定条件已经给出。

### 8.5 生成 Prompt 要求

Prompt 应在内部构造方向明确且可审计的关系图及边变化控制，公开题面只呈现自然事实和一个目标判断；不得显示关系图、关键边或边消融步骤，不得用共现、标签、实体数量或关系数量直接编码角色答案，也不得泄漏目标错误和完整答案链。

## 9. O33 内容设计：跨模态支持边界

### 9.1 能力轴

分别判断多个证据来源能够支持的事实和结论层级，处理来源间一致、互补或冲突，并给出融合后最高允许结论。

### 9.2 推理对象

- 证据来源及各自的观察事实、质量和范围；
- 来源之间的时间对齐和实体链接；
- 各来源单独支持的结论层级；
- 来源间的一致、互补和冲突；
- 题面明示的融合规则与融合后最高允许结论。

### 9.3 适用条件

1. 题面明确区分视频、信号、时间记录或外观观察等来源，不规定来源数量。
2. 每个来源的观察范围、质量或时间范围可从题面获得。
3. 目标命题具有可区分的结论层级，不规定层级数量。
4. 来源间存在互补、重叠或冲突，不能由单源直接回答全部任务。
5. 融合所需的特定业务规则必须在题面明示。

### 9.4 题面与变换

题面以自然方式说明各来源的观察事实和范围，不使用"更可靠""权威来源"等评价标签，也不要求按来源逐项作答。内容变换可调整与目标推理相关的来源覆盖范围、时间对齐、实体链接或冲突事实；其他来源定义和目标命题保持不变。

内容不变量包括未被变更的各源事实、目标命题、结论层级定义和题面明示的融合规则。不得用来源数量、来源名称、专业术语密度或所谓权威等级替代范围、时间、实体和冲突检查。

题面只询问综合现有材料能够支持何种目标结论及依据；各来源的单独支持边界、互补或冲突、实体与时间对齐、融合上限和剩余不确定性保留为内部答案结构。

### 9.5 目标错误

- source_count_treated_as_strength：来源更多即直接升级结论；
- scope_mismatch_ignored：忽略来源覆盖范围不一致；
- time_alignment_ignored：忽略时间错位；
- cross_source_entity_link_assumed：未证明来源指向同一实体；
- conflict_silently_dropped：融合时丢弃冲突；
- fusion_promoted_beyond_evidence：由线索融合直接上推身份、成分或违法性质。

### 9.6 相邻边界

- O23 判断来源内部的观测可靠性；O33 维护跨来源的支持和冲突结构。
- O27 判断一般的跨层传播规则；O33 计算多源融合后的支持上限。二者的边界由主要推理对象决定，不由来源或结论层级数量决定。
- O18 比较统计基线口径，不处理异构来源融合。
- O14 负责阻止未授权来源和事实进入题面，不测多源推理能力。

### 9.7 四场景内容种子

- 涉黄直播：信号缩小区域、视频记录人员和设备出入，两者能否绑定到同一目标并支持何种角色结论。
- 笑气线索：容器外观、充气动作、地点与时间记录分别能支持什么，为什么不能直接确认气体成分。
- 拉车门：不同摄像头的外观与路径观察是否能绑定到同一人车，不同来源冲突时结论应退到哪一级。
- 电动车：动作视频、车辆轨迹和时间同步共同支持何种协同关系，哪些身份或违法结论仍不可写。

### 9.8 生成 Prompt 要求

Prompt 应自然呈现判断各来源范围、时间、实体对齐和冲突所需的事实，内部维护单源与融合结论上限；公开题面不得要求分别判断每个来源或列出融合步骤。不得用来源数量或名称暗示证据强度，也不得泄漏目标错误和完整答案链。

## 10. 第一部分交付物

1. 能力轴和推理对象；

## 12. 场景 Adapter

### 12.1 Adapter 职责

Adapter 只完成：

- 将业务元数据归一为实体、动作、物品、观测节点、来源和结论层级；
- 提供业务术语的允许表达和禁止越界结论；
- 将题面中的可观察事实映射到 fact ID；
- 为 operator 提供适用性所需的结构字段；
- 记录 adapter version。

Adapter 不选择 operator、不生成答案、不定义目标错误、不改变 operator payload。

## 13. 适用性与路由

### 13.1 先选推理对象

Router 首先判断主要推理对象：

- 跨阶段和跨节点整体链路闭合 → O28
- 冲突绑定下的实体同一性消解 → O29
- 下一判别观测 → O30
- 多次观测独立增量 → O31
- 角色关系图关键边 → O32
- 跨模态支持与冲突 → O33

O19-O27 的既有路由映射保持不变，不在本方案中重新定义。Router 只在新算子与这些既有算子相邻时执行边界判别。

一个样本同时含多个结构时，Router 可为候选集合保留多个 eligible operator。每个候选开始进化前，再按当前目标错误所需的推理对象选定一个 selected_operator_id。若不能在不改变解题过程的情况下区分两个 operator，对应候选应判为同构并保留更具体者。

### 13.2 禁止 fallback

O28-O33 在资格通过前均不得进入主 fallback。已选算子不适用时，当前候选返回 not_applicable，不在该候选的同一次进化中改选其他 operator。候选集合中的其他候选可按各自已选 operator 独立执行；可用候选耗尽时保留父节点，不回退泛化 O10。

### 13.3 路由解释

每次选择必须保存：

- 主要推理对象；
- 满足的 required slots 与支持 fact ID；
- 被排除的相邻 operator 及原因；
- adapter version；
- operator semantic 和 applicability version。

### 14.3 O28 专属控制

- 局部链成立但整体链未闭合；
- 缺失链路与明确反证产生不同结论；
- 实体跨节点绑定发生冲突；
- 路径可达但时间窗不兼容；
- 交换表面标签不改变链路状态。

### 14.4 O29 专属控制

- 外观相似但时空关系冲突；
- 局部绑定成立但全程同一性不成立；
- 人员连续但所携物品存在转移缺口；
- 冲突解除后结论提升，冲突保留时结论不变；
- 交换候选实体标签不改变消解结果。

### 14.5 O30 专属控制

- 最可疑观测不等于最有区分力观测；
- 多个观测可并列最优；
- 所有观测均不能唯一判别；
- 最优观测不可获得时应选择次优可行项；
- 交换假设和候选观测顺序不改变选择。

### 14.6 O31 专属控制

- 同源重复不增加独立支持；
- 新点位提供独立可见特征；
- 多次低质观察仍不足；
- 次数不变但依赖关系变化；
- 累积支持增加但最高结论不变；
- 交换观察顺序不改变依赖图和结论。

### 14.7 O32 专属控制

- 共现关系不推出协同关系；
- 关系方向反转改变角色结论；
- 删除非关键边不改变目标结论；
- 删除关键边使目标结论降级；
- 交换实体标签但保留图结构时答案不变。

### 14.8 O33 专属控制

- 来源表面一致但指向不同实体；
- 同一实体但时间不对齐；
- 来源互补后结论提升；
- 来源增加但结论上限不变；
- 部分来源质量下降后融合结论降级；
- 交换来源名称不改变答案。

## 17. 测试与验收

- 来源内部的观测可靠性进入 O23，观测之间的依赖与累积增量进入 O31；
- 实体角色绑定进入 O19，关系图关键边和方向进入 O32；
- 来源内部可靠性进入 O23，一般跨层传播进入 O27，跨来源支持与冲突融合进入 O33；
- 同一隐藏结构不能通过更换 operator ID 重复生成。

### 17.3 系统级验收

1. 四场景能力缺口均有明确的主承接 family 和相邻内容边界。
2. 新 operator 的难度来自结构推理，不来自题长、选项数、术语或任务数。
3. 所有候选保持视频事实结论上限，不将身份、成分、角色或违法性质写成已确认事实。
4. 每次有效命中能归因到 operator 专属 target error。
5. 资格结论与 Router 结论分离。
6. 失败可以定位到数据、适用性、Prompt、validator、solver、Rubric 或 Judge。
7. 只有 confirmed 结果进入正式正 Memory。

## 18. 完成定义

### 18.1 第一部分完成

1. 四场景六个临时能力方向已连续映射为 O28-O33 稳定 ID，不复用、覆盖或重新解释 O19-O27，并已完成基础 registry 注册和 ID 唯一性保护；
2. O19-O27 只作为相邻内容边界，不承接或混入 O28-O33 的新能力定义；
3. O28-O33 均具备完整的能力轴、推理对象、题面构造、内容变换、不变量、目标错误、相邻内容边界和生成 Prompt 要求；
4. 算子内容不使用实体、因素、候选项、反事实、事实、节点、假设、观测、来源或语义轴的固定数量作为成题条件；
5. 第一部分只增加现有 Router 的基础规则识别和调用接线，不改动 Schema、payload、answer contract、scorer、Adapter、Router 适用性契约或质量校准、validator、资格状态、候选分支、重试策略、发布门控或回滚逻辑；
6. 人工审核信息如有记录，仅供后续人工查阅，不作为任何流程判断依据。
7. O28-O33 均可由现有 Router 按主要推理对象识别，并通过统一生成入口构造 Prompt；该可调用性不等于资格通过或正式启用。

### 18.2 第二部分完成

1. O28-O33 已在第一部分基础注册之上完成跨 family 语义冲突校验、semantic version 分配和资格状态初始化；
2. O28-O33 均有独立的四场景资格数据和相邻边界样本；
3. O28-O33 已具备机器可读前置、专属 payload、Answer Contract 和 scorer 映射；
4. 每个 operator 已通过独立 forced qualification 或被机制指标判定为证据不足；
5. 未资格化 operator 不进入主 Router、fallback 或正式 Memory；
6. 场景 adapter 不改变 operator 语义和答案方向；
7. 自然路由 holdout 能报告适用性和 operator 混淆，而不是只报告平均降分；
8. 候选集合不设固定数量限制，每个候选的一次进化只使用一个 selected_operator_id，且不在候选内切换 operator；
9. manual_review_record 如有记录，不输入 Router、validator、scorer、状态机、回滚或发布判定。
