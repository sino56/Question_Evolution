# 四类视频研判场景下的算子与问题进化评估报告

## 读者、目标与证据口径

**读者**：负责 PoliceQA 题目进化、评测设计和算子扩展的研发人员。

**读完后应能完成的动作**：把当前 O10--O18 从"已经注册的算子集合"拆分为"已有初步有效证据""已证实不适配或无效""尚未完成资格测试"三类，并按本报告的优先级重排下一轮数据、路由和 Prompt 改造。

本报告复核了 19 条人工入选样本、Round 0 到 Round 5 的完整实验产物，以及当前主流程、路由、候选校验和 O10--O18 的 Prompt 合约。分数均为流程使用的 Qwen 决策得分率，范围为 0--1；`effective_boundary_probe` 是自动标签，不等同人工确认的模型能力边界。

结论主要来自结构化产物中的题目、路由、候选、校验、得分、effect 和 state。虽然实验保留了回答与 judge 明细，本报告没有逐条人工重判每一份回答和 rubric，因此不把任何自动命中升级为"已确认边界"。尤其是 effect 中的 focus 命中目前主要依赖关键词覆盖，不能单独证明回答确实犯了目标推理错误。

## 一、结论摘要

这批实验验证了"用可观察事实关系替代审慎措辞来出题"的方向是必要的，但尚未验证当前算子集在四类场景上稳定有效。57 次实际进入重新评分的进化中，只有 5 次自动标记为有效边界探测，25 次进化后反而升分；最终 19 条样本中只有 5 条停在 `effective_boundary_sample`，其余 14 条均因达到最大轮数而未收敛。

当前最有价值的正向信号集中在三个窄能力点：

- O10 在"人、物、动作、轨迹的连续绑定"上压出了两个单样本信号：笑气运输样本 18757 从 0.838 降至 0.617，拉车门后逃逸路线样本 34176 从 0.932 降至 0.463。
- O13 在"一个新增事实是否足以推翻原有推理连接"上压出了两个信号：直播窝点角色关系样本 24804 从 0.986 降至 0.778，伪装维修工盗车样本 34626 从 1.000 降至 0.762。
- O16 在"相近正常解释究竟解释外围现象还是核心异常"上压出一个信号：居民楼窝点角色模式样本 22595 从 0.824 降至 0.631。

这些都只是单样本、自动中置信度证据。它们说明现有体系可以在部分"证据关系和结论层级"问题上制造有意义的最小对照，但不能据此宣称任一算子已跨场景稳定可用。

本轮最明确的系统问题不是候选题的大规模格式失控，而是适用性、路由和效果归因混在一起：126 条候选中有 41 条直接 `not_applicable`，仍在候选校验中记为通过；O11、O14、O17、O18 没有形成任何可归因的最终评分结果；Round 1 又让 17 条实际进化都使用 O10。于是"算子没有效果""样本不适配""算子没有生成""题目生成后模型更容易答"四种状态没有被实验设计清楚地区分。

## 二、当前系统如何工作

当前主链不是单一的"把题改难" Prompt，而是一个带路由和状态的闭环：

1. Round 0 对原题生成候选模型答案并评分，得到基线得分率。
2. 画像阶段为样本生成 `sample_profile` 和 `overscore_diagnosis`；分流阶段据此决定进化、透传或停止。
3. 路由阶段综合诊断、上一轮状态和正负 memory，给出 primary、backup 与 avoid 算子。
4. 生成阶段按算子生成一个或多个候选；本地规则和独立校验控制题长、任务数、选项数、反事实数、题外知识和重复题型。
5. 候选选择阶段保留一条主链题目；其后重新生成参考答案、rubric 和 score prompt，再对候选模型重新评分。
6. effect 阶段比较前后得分，并以题目有效性、重复风险、得分下降和 focus 对齐形成自动标签；state 与 memory 再决定下一轮换算子、回滚或停止。

该链路的优点是可追溯：每一轮都有画像、路由、候选、校验、评分和状态记录。它也有两个会直接影响本报告解读的边界：

- 题目变化后会重生成参考答案和 rubric。得分变化因此是"题目、参考答案、rubric 与回答"共同变化后的结果，不能只归因给题目算子。
- effect 的"focus 对齐"并非人工判定错误链。它目前以答案文本与 `expected_evaluation_focus` 的词项匹配为主，适合筛选，不能替代回答级审计。

## 三、当前问题进化 Prompt 与算子合约

生成 Prompt 的共同策略是事实约束：只向生成模型提供原题和参考材料作为可观察事实过滤器，不提供候选模型答案、原 rubric、诊断文字、路由理由和评测 focus。它要求先区分可观察与不受支持的事实；只压一个可归因错误；所有选项保持主体、时段、言语行为和表面长度平衡；只改变一个决定性事实，并以 JSON 返回事实 ID、答案键、反事实翻转与干扰项理由。

这避免了旧式"写得更谨慎、更多补强建议、更多限定"的伪难度，也避免生成模型照抄评分答案。代价是生成端看不到样本画像和诊断所定义的目标错误，只有较抽象的 operator contract 与原始材料可依赖；在事实槽位不丰富或诊断非常具体时，算子容易退化为泛化的最小改写。

### O10--O18 的设计目的与本轮证据

- **O10 近似判断竞争**：只改变一条决定性画面事实，考察该事实是否改变同一结论。它是本轮实际测试最多的算子，21 次重新评分平均得分变化为 -0.009，其中 8 次升分、5 次无清晰效果、4 次待人工复核、2 次自动有效、2 次满分不降。它在 `18757` 和 `34176` 有价值，但作为默认兜底算子过宽，不能继续把"所有视频证据题"都送给 O10。
- **O11 盲区不可见状态归因**：用可见端点、时长和预期重现点比较盲区中的解释。本轮 6 次均返回 `not_applicable`，没有实际进化得分。它需要真实的盲区端点和可比较时序；当前数据的多数"遮挡、断点、连续性不足"并不等于可用的端点时序任务。
- **O12 强线索替代未闭合门槛**：比较只有 X 与 X+Y 的共同条件闭合。6 次重新评分平均得分变化 -0.067，没有自动有效命中，包含 2 次升分、3 次无清晰效果和 1 次满分不降。现有样本常有多个证据，但并不天然给出两个独立且共同必要的条件，路由不能把"多条件"直接等同于 O12 适用。
- **O13 最小推翻事实**：在同一推理链中识别哪条新增事实使原有连接失效。12 次重新评分平均下降 0.037，有 2 次自动有效、6 次待人工复核、3 次升分、1 次无清晰效果。它是除 O10 外最值得保留并做定向资格测试的算子；但其成功仍集中在角色/关系和伪装/动作链两个样本。
- **O14 信息闭包**：设计上只做全局校验，不独立成题。本轮 7 次 `not_applicable` 正是合约的预期行为，不能被计为"算子无效"。它应从 router 的候选席位中移出，改成所有候选的生成后诊断项。
- **O15 反事实门槛迁移**：只改一个核心事实，比较结论变化。10 次重新评分平均得分变化 -0.034，7 次升分、3 次待人工复核、零自动有效。它不是没有价值，而是当前 Prompt 只约束"单变量"，没有要求变化后的目标命题、干扰项和 rubric 形成可判的最小反事实；一个样本还因出现两个反事实被校验拒绝。
- **O16 相近正常解释归一化**：只引入一个正常解释和一个可观察判别事实。8 次重新评分平均得分变化 -0.074，5 次升分、2 次无清晰效果、1 次自动有效。`22595` 的成功说明"正常解释覆盖范围"是有价值的能力轴，但该算子不能把任意低分/噪声样本都改为正常解释题。
- **O17 处置触发与事实定性门槛**：仅当题面明确给出两套业务规则与阈值时启用，默认禁用。本轮 10 次 `not_applicable`，只有 1 次生成还因反事实数超限被拒，故没有效果证据。路由不应在无明确规则文本的 PoliceQA 视频样本上反复把它排为 primary 或 backup。
- **O18 基准样本范围错配**：需要两个同域、口径明确的基线及一个可比较观测。本轮 18 次全部 `not_applicable`。当前四场景数据几乎没有可用的统计基线字段，说明这是数据能力缺口，不是生成模型不愿出题。

## 四、数据覆盖范围与局限

19 条样本全部是"视频可见事实与结论强度边界"问题，入选时都被限定为不能直接下身份、违法性质、同伙分工或法律定性的 `strong_partial_case`。四类业务场景及数量如下：

- **拉车门盗窃 6 条**：服务区、商场停车区和货运区中的接触动作、物品同一性、人车货链与逃逸轨迹。
- **涉黄网络直播与居民楼窝点 3 条**：信号与视频的融合范围、人员角色关系、接客/看管/普通住户的模式区分。
- **电动车盗窃 5 条**：破坏进入与未拔钥匙、两车控制、装卸运输、望风协同和伪装维修工动作链。
- **笑气线索研判 5 条**：气瓶/纸箱运输、充气交付、重复往返、仓储搬运和娱乐场所后门接力。

这是一组有意收窄的发现集，不是 PoliceQA 的代表性测试集。它覆盖了视频轨迹、行为模式、物品/车辆关联与证据结论边界，却几乎没有以下条件：明确业务阈值、可比较统计基线、结构化多源传感器冲突、已标注盲区端点、法律要件、资源受限的处置决策。因此不能据此给 O11、O17、O18 判失败，更不能外推到非视频类 PoliceQA。

Round 0 的 19 条平均得分为 0.914，17 条不低于 0.8，说明它们符合"高分但可能虚高"的探测入口。最终文件的平均分为 0.794，四类场景的基线到最终均值变化分别为：拉车门 0.871 到 0.756、涉黄窝点 0.969 到 0.742、电动车 0.949 到 0.838、笑气 0.898 到 0.827。这个总体下降不能直接解释为系统成功，因为最终集合同时混有已命中样本、仍在当前进化题上的未完成样本和回滚样本；应以逐次可比的 effect 记录为主。

## 五、实验整体结果

五轮共形成 126 条候选记录：67 条是真正生成的进化题，41 条 `not_applicable`，18 条是透传。候选校验报告 121 条"通过"，但该数字包含 `not_applicable` 与透传；真正的题目生成有效率不能从 121/126 推导。

57 条被选中并完成重新评分的进化题，其自动效果分布为：

- `effective_boundary_probe`：5/57，8.8%。
- `needs_manual_review`：13/57，22.8%。
- `score_increased`：25/57，43.9%。
- `no_clear_effect`：11/57，19.3%。
- `full_score_no_drop`：3/57，5.3%。

"升分"占比最高，说明目前的主要风险不是题目太难或不可答，而是改写常常把任务改得更显性、更窄或更契合候选模型已有策略。单看题长、任务数、外部知识与重复的规则校验无法发现这一点。

轮次层面，Round 1 的 17 次实际进化全部为 O10，这是最明显的路由集中偏差。Round 2 开始才转入 O12/O13；Round 3 到 Round 5 才出现 O15/O16 的实测。O11/O14/O17/O18 始终未获得可归因的有效评分。由此不能比较九个算子的优劣，只能比较五个实际生成并完成评分的算子。

## 六、哪些场景和样本产生了信息

### 拉车门盗窃

- **34176**：原任务是服务区后备箱案中，判断外貌连续追踪与"人、物、动作、时间"联合绑定的差异。O10 使得分从 0.932 降到 0.463，是本轮唯一高置信度自动命中。这个样本支持继续测试"跨点位连续链中哪一事实真正决定同一目标"这一能力，而非泛化为"拉车门题适合 O10"。
- **21725**：商场停车区锁车反馈、接近时差和拉门动作的时序链。O10 首轮从 0.878 升到 0.970，后续 O12 无效、O10 再试仍无效，Round 5 的 O13 仅从 0.917 降至 0.833 且待人工复核。现有算子没有把"可见接触动作"与"设备功能不能由画面确认"稳定压成同一主轴。
- **23904**：货运区人、货、转运车、驶离方向的连续关系。O10 从 0.797 升至 0.867，O12 后又升至满分，后续 O11 不适用。问题可能不是缺少更多对比，而是缺少"物品同一性、所有权与可见转运分别支撑何种结论"的多跳证据图算子。
- **28996**：服务区后备箱物品同一性和离场路径。O10、O13、O15、O16 都曾升分或只待复核，最终仍未完成。该题需要把"相似物品""取物画面""路线连续性"分别定位到不同子结论，现有单事实翻转不够。
- **18436**：夜间连续拉车门试探。O15 曾从 0.930 升至满分，O11 不适用；无边界证据。样本包含低能见度与连续行为，适合观测可靠性或累积证据阈值，而不是当前反事实模板。
- **31858**：尾随入场、接近、动作、出场的节点链。O13 有小幅下降但未确认，O15/O16 均升分或无效。它同样暴露了动作链缺口定位与实体连续性没有被独立建模。

### 涉黄网络直播与居民楼窝点

- **24804**：多出入口和 ATM 周边视频中的组织、参与、辅助与普通出现者角色分层。O13 从 0.986 降至 0.778，成为自动有效样本。有效点是"一个最小事实是否足以维持角色推理连接"，而不是把取现或同进同出直接定性。
- **22595**：居民楼中接客女性、接送看管和普通住户的重复模式区分。O13 的下降 0.967 到 0.824 仍待复核，O15 反而升分；O16 最终从 0.824 降至 0.631 并自动命中。该结果支持 O16 在"频繁出入是否被正常居住解释覆盖"的场景中继续做重复测试。
- **32575**：娱乐场所直播窝点的信号缩小范围、设备搬运和人员出入。O12 满分不降；O15 从 1.000 降到 0.872、O13 从 0.872 降至 0.816，均待人工复核。它包含信号-视频融合，但现有算子没有表达"两个证据源各自可靠度与可推结论上限"的跨模态冲突。

### 电动车盗窃

- **34626**：伪装维修工接近、处理车辆、车辆移动和离开的完整链。O10 首轮升至满分，O13 随后从 1.000 降至 0.762 并自动命中。该反差说明外观伪装并不是有效难点，动作与车辆移动之间的必要连接才是。
- **17815**：物流园多辆车装载、运输、卸载的三段链。O13 和 O15 只产生小幅待复核下降，O16 无效或升分。它需要处理"车上轮廓是否同一物、装卸点与运输点是否连通"的跨镜头实体解析。
- **3564**：破坏进入与未拔钥匙溜门的动作链。O10/O12 无效，O13 在 Round 4 仅从 0.983 降至 0.933，O16 又升至满分。说明把一个动作事实改写为反例尚未迫使模型区分两种竞争机制。
- **30155**：一人控制两辆电动车的控制方式与路线接力。O10 有 0.142 的待复核下降，后续 O13 无效、O10 再试升至满分。它更适合"关系图中的主车/被带走车/控制边"的结构化算子。
- **35211**：剪锁/推车者与疑似望风人员的同步、观察、汇合关系。O10 升至满分，O11/O17 不适用，O16 也升分。现有算子没有把"共现、同步、重复、汇合"组合成协同关系的最小可识别模式。

### 笑气线索研判

- **18757**：仓库至娱乐场所后门的车辆、物品、地点与装卸关系。O10 从 0.838 降至 0.617 并自动命中，证明连续关系是否成立可以成为有效难点；但不能越过视频事实断言气体成分或非法经营。
- **34455**：改装面包车、气瓶/纸箱和多摄像头接力的稳定运输关系。O10 小幅下降后，O12 在 Round 5 从 0.833 升至 0.983；还有一次 O10 因与原题相同而被拒。说明"重复共现"本身并不能稳定产生难度，需要显式区分实体同一性、关系稳定性和违法性质。
- **24136**：气球充气准备、手递手交付与接触对象变化。O10/O13/O16/O15 都升分；O17 又因双反事实被拒，O11/O14 不适用。该样本的"准备、交付、销售、成分"是多个相邻命题，现有单轴要求没有阻止实际改写或评分把它们混合。
- **27965**：交付点与固定往返点的携带物变化和补货轨迹。O10、O12、O13、O15 都升分或无效。它所需的是"哪一个观测最能区分存放/二次分装与普通往返"的主动判别信息，而非 X 加 Y 的必要条件。
- **30470**：仓储点单次搬运与批量分装转运模式。O10 首轮升分，O16 再次升至满分，O11/O17/O18 不适用。样本适合累积证据与正常物流替代假设的量化比较，但目前没有可用统计基线，O18 因而无法生成。

## 七、当前算子和 Prompt 的不足

### 1. 路由没有做硬适用性过滤

O11、O17、O18 的合约都有明确前置条件，但 router 可以在没有盲区端点、业务阈值或双基线时把它们安排进候选队列。结果是 41 条 `not_applicable` 占全部候选 32.5%，并消耗候选席位。应在调用模型前用结构化事实槽位检查适用条件；不满足就不占候选预算，并立即尝试下一个可用 backup。

### 2. O14 的职责被错误地放进候选算子列表

O14 明确是校验型，不产出独立题面。当前将它当作 candidate operator 会得到"校验通过的透传记录"，既稀释了生成成功率，也让 router 看似覆盖了 O14。应把 O14 改为生成后、候选选择前的统一 lint/事实闭包检查，不参与 primary/backup 排名。

### 3. 默认 O10 掩盖了真正的路由效果

Round 1 的 17 次实测全部使用 O10，原因是诊断词和 fallback 都倾向证据充分性。O10 的成功与失败样本都很多，说明它不是无用，而是语义过宽。应把"证据相关"拆成至少三类：实体同一性、链路连续性、结论层级；只有存在单个决定性事实反转时才进入 O10。

### 4. 生成 Prompt 缺少受控的任务适配信息

现有 Prompt 正确地不暴露候选答案和 rubric，但也不提供明确的 `target_claim`、允许的结论上限、事实槽位表、待检验失败点和场景 adapter。生成模型只能从原题和参考文本自行抽取结构，这会造成"题目更清楚"而非"针对目标错误更难"。建议在不泄露候选答案的前提下，提供代码生成的最小 operator card：目标命题、可用事实 ID、允许变动字段、必须保留的竞争解释、禁止触及的结论上限和本轮唯一测试能力轴。

### 5. 候选选择只验证形式，未验证目标推理负荷

当前校验能拒绝过长、多任务、多反事实、重复和题外知识，但无法判断候选是否真的让模型必须完成算子声称的推理。67 条真实生成候选中只有 4 条被规则拒绝，57 条被选题中却有 25 条升分，说明形式校验通过远不等于题目对目标能力有效。候选选择应加入离线资格诊断：反事实一致性、选项表面平衡、目标事实删除后答案是否不可判、强模型可答性，以及固定回答上的 rubric 可区分性。

### 6. 效果归因不足以决定 memory

自动 effect 同时受回答采样、重新生成的 rubric、judge 与问题变化影响。且 focus 对齐主要是词项匹配。正 memory 应只收录人工复核或至少双 judge 与多次回答一致的命中；失败 memory 应区分 `not_applicable`、生成违规、题目无增益、升分、评分不可靠，不能把它们都当成"该算子失败"。

## 八、现有集合尚未覆盖的能力

以下不是简单增加更多题型，而是当前四场景中的真实业务推理需求，现有 O10--O18 无法稳定表示：

- **多跳证据图闭合**：人、车、物、动作、时间和镜头之间至少两跳关系是否同时成立。例如 `23904`、`17815`、`34455` 不是一个事实能翻转的任务。
- **跨镜头实体解析与冲突消解**：外观相似、遮挡、换装、物品不清晰时，哪些属性足以支持同一实体，哪些只能维持候选关系。`34176`、`28996`、`30155` 都需要这一能力。
- **多假设与判别信息选择**：不是"正常解释是否成立"，而是在多个合理解释下，哪个新观测最能减少不确定性。`27965`、`35211`、`32575` 是代表。
- **跨模态证据校准**：信号、视频、时间、物品外观各自支持什么结论，冲突时结论应退到哪一级。`32575` 的信号范围与人员角色、笑气样本中的物品外观与成分，是当前的空白。
- **累积证据与观测可靠度**：夜间、遮挡、一次观察、重复观察的可靠度如何改变结论，而不是只换一个事实。`18436`、`30470`、`35211` 需要这类能力。
- **关系网络与协同角色归因**：共现、同步、等待、汇合与分工不是同一证据强度。`24804` 和 `35211` 需要结构化角色图，而当前 O13 只能局部推翻一条边。

## 九、建议新增或拆分的算子

优先新增的算子应先做离线资格实验，不要直接加入线上 router。

1. **O19 多跳链路闭合**：题面给出人-物、物-车、车-路径等候选边，只改变一条关键边的可辨识度或时间可达性，要求判断哪个子结论仍成立。适用于 `23904`、`17815`、`34455`；验收条件是删去关键边后目标结论不可唯一确定，且不引入所有权或违法性质。
2. **O20 实体同一性冲突消解**：围绕两段镜头中的人/车/物，给出支持同一与支持不同的等强事实，要求判断能否合并实体及结论上限。适用于 `28996`、`30155`、`34176`；重点防止把外貌相似或单一颜色直接当作同一性。
3. **O21 多假设判别观测**：给出两到三个保持可行的解释和可获得的一个新观测，要求选择最能区分解释的观测，而不是直接定性。适用于 `27965`、`35211`、`32575`；它应成为 O16 的上位补充，不预设"正常解释"方向。
4. **O22 观测可靠度与累积阈值**：保持事件不变，只调整可见度、遮挡、重复次数、时间同步或来源独立性，要求给出结论可以到达的层级。适用于 `18436`、`30470`、`21725`；不应伪造统计阈值。
5. **O23 角色关系图最小边**：针对组织、协助、望风、普通出现等角色，删除或替换一条关系边，判断哪一个角色推断失效。适用于 `24804`、`35211`；它比 O13 更适合处理多人的协同网络。
6. **O24 跨模态结论上限**：显式标注视频、信号、时间和外观事实各自的来源，要求比较单源与融合后能支持的最大结论。适用于 `32575`、笑气物品识别类样本；它不应把融合直接变成违法成分或身份确认。

O17 与 O18 不应删除，但应迁到有相应结构化数据的专门实验池：O17 需要真实业务规则库，O18 需要有口径、样本量与纳入条件的历史统计。没有这些输入时，不应进入本批视频事实数据的覆盖率计算。

## 十、下一轮改造优先级与验证方法

1. **先做算子适用性预检**：为每个算子定义机器可读的事实槽位需求，router 只从满足需求、已启用、非校验型的算子中选 primary/backup；`not_applicable` 立即换下一个候选。验证指标是 `not_applicable` 不占候选预算，且每个被选算子都有可审计的适用证据。
2. **将 O14 移为全局 lint，收紧 O17/O18**：O14 只记录闭包违规，O17/O18 只有在规则/基线字段存在时才可被路由。验证指标是候选记录的"生成、透传、未适用、校验失败"四类状态互斥，覆盖率报表不再混淆。
3. **重做 O10 的拆分路由并资格测试 O13/O16**：用均衡的场景-能力轴矩阵，而不是连续轮次的首个可用算子。每个算子先在 8--12 个已满足适用条件的样本上做父题对照、多个候选和重复回答。验证指标是有效命中率、升分率、未适用率、回答/评分方差分别报告。
4. **给生成 Prompt 加最小结构化 operator card**：保留不传候选答案和原 rubric 的原则，但传入事实 ID、目标命题、结论上限、唯一能力轴、可变槽位和必须保留的竞争解释。验证指标是题面事实 ID 与输出 metadata 的一致率、关键事实消融测试通过率、人工判定的任务漂移率。
5. **把效果判定升级为证据链**：每次自动命中都保存父题/子题对、同一回答的多次 judge、目标 rubric 项、回答中命中或遗漏的原句；memory 仅接收人工或双 judge 确认的样本。验证指标是自动命中经人工复核后的确认率，以及"题目变化"和"rubric/judge 波动"可分离的比例。

## 十一、收尾判断

本批实验是有价值的发现实验，不是算子有效性验收。它已证明事实关系导向的 Prompt 在少数连续绑定、最小推翻和相近解释样本上能够压出候选模型的具体错误；也清楚暴露了当前数据与算子前置条件不匹配、O10 路由过度集中、候选有效性只做形式校验、自动 effect 证据不足等问题。

下一步不应先扩写"让题更难"的通用 Prompt。应先把适用性预检、候选状态分类、O10 的语义拆分和 O13/O16 的受控资格实验做扎实；随后用多跳链路、实体解析、多假设判别、观测可靠度和关系图算子补齐这四类视频场景真正缺失的推理能力。
